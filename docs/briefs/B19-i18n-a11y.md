# B19 — Internationalisation and accessibility
**Crates** `heartsim-ui`, `heartsim-app`, `assets/locales` · **Model** Haiku · **Milestone** M5 · **Depends on** UI panels existing
(can start with the toolbar and strip).

## Scope
1. Fluent (`fluent`/`fluent-bundle`/`unic-langid`): `assets/locales/{en,it}/*.ftl`; `t!("key")` macro; language from `sys-locale`
   with override in settings; all user-visible strings moved to keys (lint: no string literals in `ui.label` except debug).
2. Accessibility: AccessKit enabled (eframe feature on), every interactive widget has a label; keyboard shortcuts documented
   (space pause, ←/→ scrub, +/- speed, 1–7 views); high-contrast theme; reduced-motion flag disables auto-rotate and shock flash;
   colour-blind-safe LUT option.
3. Italian translation of all keys (the primary user is Italian-speaking); German/French/Spanish stubs.

## Acceptance tests
A test iterates all `.ftl` files and asserts every key in `en` exists in `it`; `egui_kittest` AccessKit tree contains labels for
toolbar controls; switching language at runtime relabels the toolbar.
